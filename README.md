# ESP Web Tool

A web app to flash your ESP32 or ESP8266 through your browser. Open-Source, free, and easy to use.

Have a look [https://esptool.spacehuhn.com/](https://esptool.spacehuhn.com)

## Credits

Flashing is done with [esptool-js](https://github.com/espressif/esptool-js) by Espressif.

## Installation

```
git clone https://github.com/spacehuhntech/espwebtool
cd espwebtool
npm install
npm start
```
